mediClinic — React Core Clinic Management SaaS UI
================================================
This project has been converted to React and Vite.

Run in PowerShell:
  npm.cmd install
  npm.cmd run dev

Open the URL Vite prints. See README.md for source mapping and verification.
Build: npm.cmd run build

Primary ERD: Clinic_Professional_ERD_Diagrams.pdf
Core administration and operations only; no specialty or Medical Core Phase 2 UI.
All records are fictional. Forms are review-only, without backend transactions.
