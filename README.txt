mediClinic — bilingual clinic workspace
=======================================
React and Vite frontend redesigned for the final reviewed Clinic Core ERD.

Run in PowerShell:
  npm.cmd install
  npm.cmd run dev

Open the URL Vite prints. See README.md for source mapping and verification.
The root opens Login. Register Clinic and Onboarding are frontend demo flows.
Build: npm.cmd run build

Primary ERD: Clinic_Core_ERD_Final_Reviewed.pdf
The UI covers clinic operations, billing, patient history and a clinical visit workspace.
All records are fictional. Forms are review-only, without backend transactions.
